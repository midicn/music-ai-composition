## 交付的是文件，不是临时链接

先与接收方约定文件类型、声道、采样率、位深、时长范围和命名。响度要求按用途确认；广播建议值不能直接套在所有平台。原生MIDI、分轨或工程文件只有在实际可提供时才列为交付物。

| 文件 | 内容与版本 | 起点、时长 | 技术规格 | 状态 |
|---|---|---|---|---|
| cue_v05_mix.wav | 确认版立体声混音 | 与画面标记对应，保留尾音 | 按接收方约定填写实测值 | 已打开试听 |
| cue_v05_stems/ | 实际可用的分轨 | 共同起点 | 分别记录声道与格式 | 已检查齐全 |
| notes.txt | 修改记录、素材来源、缺失项 | 对应v05 | 可读文本 | 接收方可读 |

上表是虚拟教学项目，文件并未由本站生成。可按项目加入校验值以确认传输完整性；校验值相同不能证明音乐质量或使用权利。

## 推荐目录

```
project_delivery/
  mix/
  stems/
  notes.txt
  file-list.txt
```

只保留本次约定的交付版本，工作中的中间文件另存。把已知缺失写清楚，例如“无原始工程，分轨来自混音分离”，不要用一个空文件夹暗示已经交付。

## 发出前的最后一次打开

复制到一个新位置，按清单逐个打开；核对开头、结尾、声道与文件名。如果附工程，检查外部采样和插件依赖。将接收方已确认的规格与最终版本一同存档，避免下次修改时把试听文件当成母版。

## Deliver files, not temporary links

Agree file type, channels, sample rate, bit depth, duration range and naming with the recipient. Confirm loudness for the intended use; a broadcast recommendation is not a universal platform target. List native MIDI, stems or projects only when they are actually available.

| File | Contents and version | Timing | Specification | State |
|---|---|---|---|---|
| cue_v05_mix.wav | Approved stereo mix | Picture origin and complete tail | Agreed, measured properties | Opened and auditioned |
| cue_v05_stems/ | Available stems | Common origin | Channels and formats per file | Completeness checked |
| notes.txt | Revisions, sources and missing items | Corresponds to v05 | Readable text | Recipient can read it |

This is a fictional teaching package, not audio generated by this site. A checksum can help confirm transfer integrity where needed; a matching checksum does not establish musical quality or rights.

## A simple folder structure

```
project_delivery/
  mix/
  stems/
  notes.txt
  file-list.txt
```

Keep the agreed delivery version here and store intermediate work separately. State missing material explicitly, such as “no original project; stems were separated from a mix.” An empty folder is not a deliverable.

## Reopen before sending

Copy the package to a fresh location and open each listed item. Check starts, endings, channel layout and names. For a project file, check external samples and plug-in dependencies. Archive the approved specification with the final version so a later revision does not accidentally start from a listening copy.
